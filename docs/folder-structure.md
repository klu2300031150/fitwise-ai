# Folder Structure

- `frontend/` React + Vite customer and seller UI.
- `backend/` FastAPI application, models, schemas, and services.
- `ai/` vision, OCR, NLP, fabric, and recommendation heuristics.
- `database/` SQL schema and seed data.
- `docs/` architecture, API, pitch, and future roadmap.
- `docker/` Dockerfiles used by `docker-compose`.
