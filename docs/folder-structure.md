# Folder Structure

- `frontend/` React + Vite customer and seller UI.
- `backend/` FastAPI application, models, schemas, and services.
- `ai/` Computer Vision, OCR, NLP, Bayesian recommendation, and rule-based AI processing.
- `database/` PostgreSQL schema, seed data, and data models for users, products, measurements, charts, and recommendations.
- `docs/` architecture, API, pitch, and future roadmap.
- `docker/` Dockerfiles used by Docker Compose for FastAPI, PostgreSQL, Redis, and AI services.
